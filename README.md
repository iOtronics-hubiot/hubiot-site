# Hubiot Website V5

V5 corrects the UX and content problems identified in V4.

## Key changes
- restores the original Hubiot logo
- reduces headline scale substantially
- gives every page a distinct content purpose and layout
- uses the original high-resolution Hubiot and iOtronics artwork
- removes low-detail SVG illustrations
- presents iOtronics as a contained featured platform on the homepage
- retains the accepted website flow
